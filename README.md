# BRICKBREAK

A free, open-source brick-breaker (Breakout-style) arcade game. Pure HTML/CSS/JS in a **single file** — no build step, no dependencies, no ads, no install.

## Play

Open `index.html` in any modern browser. That's it.

Or enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root) to play it online.

## Controls

| Input | Action |
|---|---|
| Mouse / touch | Move paddle |
| `←` `→` or `A` `D` | Move paddle (keyboard) |
| `Space` / click | Launch ball |
| `P` / `Esc` | Pause |

## Features

- Endless levels with increasing speed, extra rows, and 2-hit armored bricks
- Power-ups: **W**ide paddle, **M**ulti-ball, **S**low motion, **+** extra life
- Combo scoring — chained brick hits without touching the paddle multiply points
- Juice: particle bursts, screen shake, ball trail, paddle squash, floating score text, damage flash
- Synthesized sound effects via WebAudio (no audio files)
- High score saved locally in your browser
- Fully responsive, works with mouse, keyboard, and touch
